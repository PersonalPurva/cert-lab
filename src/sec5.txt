+ Tailgating, by allowing one person through at a time

Q A bollard is used to:
+ Physically block vehicles from ramming a building
- Filter network traffic

Q "Faraday cage" protects against:
+ Electromagnetic signals entering or leaving (eavesdropping/interference)

Q Biometric access control is which authentication factor?
+ Something you are
- Something you know

+ Something you have
- Something you know
- Something you are
- Somewhere you are

Q Why use security lighting and clear sightlines?
+ They deter intruders and improve camera/guard effectiveness
- They encrypt data
- They speed up Wi-Fi
- They are decorative only
E Environmental design (CPTED) reduces hiding spots.
Q A "honeyfile" or honeytoken is:
+ A decoy file/credential that alerts defenders when touched
- A backup file
- An encryption key
- A firewall log
E Any access to it strongly implies an intruder.

#D 24|5 Program|Governance, policies and standards|Summarize governance, policies, standards and frameworks.
Q What is the difference between a policy and a procedure?
+ A policy states what/why (high level); a procedure states step-by-step how
- They are identical
- A procedure is higher level
- A policy is technical only
E Standards and guidelines sit between them.
Q An Acceptable Use Policy (AUP) defines:
+ How employees may use company systems and data
- The backup schedule
- Firewall rules
- Encryption algorithms
E Users typically sign it during onboarding.
Q A "standard" (vs a policy) is:
+ A mandatory specific rule that supports a policy (e.g., "AES-256 for encryption")
- An optional suggestion
- A high-level goal
- A legal contract
E Guidelines are recommended, not mandatory; standards are mandatory.
Q What is a security framework used for?
+ A structured set of best practices to build and measure a security program
- Encrypting disks
- Blocking ports
- Writing malware
E Examples: NIST CSF, ISO 27001, CIS Controls.
Q "Separation of duties" prevents fraud by:
+ Requiring more than one person to complete a sensitive task
- Giving one admin all power
- Encrypting logs
- Backing up daily
E No single person can both request and approve a payment, for example.
Q "Mandatory vacation" and "job rotation" are controls that:
+ Help detect fraud and reduce dependence on one person
- Improve morale only
- Are unrelated to security
- Replace backups
E Fraud often surfaces when the usual person is away.
Q Onboarding and offboarding processes matter because:
+ They ensure access is granted correctly and fully removed when someone leaves
- They are HR-only concerns
- They speed up hiring
- They are optional
E Orphaned accounts of ex-employees are a major risk.
Q What is "due care" vs "due diligence"?
+ Due diligence is investigating/planning; due care is acting on it responsibly
- They are the same
- Due care is only legal
- Due diligence means ignoring risk
E Diligence = doing your homework; care = the ongoing responsible action.

X # Accounts are created only via approved onboarding tickets with manager sign-off.
X # Access is reviewed quarterly; unused/excess access is revoked.
X # Accounts are disabled within 1 hour of termination.
V each statement is enforceable and auditable
T Map to a framework
S Pick three CIS Controls (or NIST CSF functions) and give one action your org would take for each.
X # e.g. NIST CSF: Identify -> asset inventory
X #                Protect -> MFA + patching
X #                Detect  -> central logging/SIEM
V each function has a concrete action

#D 25|5 Program|Risk management|Apply risk-management concepts and calculations.
Q What is "risk" in security terms?
+ The likelihood of a threat exploiting a vulnerability and the resulting impact
- Any change to a system
- A type of malware
- A firewall rule
E Risk = likelihood x impact, roughly.
Q The four risk-response strategies are:
+ Accept, Avoid, Transfer, Mitigate
- Ignore, Delete, Encrypt, Backup
- Detect, Deter, Delay, Deny
- Buy, Sell, Hold, Trade
E Transfer often means buying insurance; mitigate means adding controls.
Q Buying cyber-insurance is an example of risk:
+ Transference
- Avoidance
- Acceptance
- Mitigation
E You shift the financial impact to a third party.
Q "Residual risk" is:
+ The risk that remains after controls are applied
- The risk before any controls
- Risk that was transferred
- Zero always
E You cannot usually reach zero; leadership accepts the residual.
Q SLE x ARO equals:
+ ALE (Annualized Loss Expectancy)
- Residual risk
- RPO
- The asset value
E Single Loss Expectancy x Annual Rate of Occurrence = expected yearly loss.
Q If an asset is worth $10,000 and an incident destroys 50% of it, the SLE is:
+ $5,000
- $10,000
- $2,500
- $500
E SLE = Asset Value x Exposure Factor = 10,000 x 0.5.
Q A "risk register" is:
+ A living document listing risks, owners, and treatment status
- A firewall log
- A backup index
- A password vault
E It tracks each risk from identification to closure.
Q Qualitative risk analysis uses:
+ Ratings like high/medium/low rather than exact numbers
- Only dollar figures
- Packet captures
- Hash values
E Quantitative analysis uses numbers (SLE/ALE); qualitative uses judgment scales.

X # ARO = 1/4 = 0.25 per year
X # ALE = SLE x ARO = 5000 x 0.25 = $1,250 per year

T Build a mini risk register
S Add three risks for a web app, each with likelihood, impact, response strategy, and owner.
X # SQLi -> High/High -> Mitigate (WAF+prepared stmts) -> Dev lead
X # DDoS -> Med/High -> Transfer/Mitigate (CDN scrubbing) -> Ops

- A network protocol

T Automate a safe check
S Write a short script that checks disk usage and alerts (logs) if over 80%, and make it idempotent.

#D 29|4 Operations|Endpoint and email security|Protect endpoints and email against modern threats.
Q EDR (Endpoint Detection and Response) provides:
+ Continuous monitoring, detection, and response on endpoints
- Only signature antivirus
- Disk encryption only
- A firewall
E EDR sees behavior and enables remote investigation/containment.
Q How does EDR differ from traditional antivirus?
+ It focuses on behavior/telemetry and response, not just known-signature files
- It only scans on demand
- It cannot quarantine
- It has no logging
E AV catches known malware; EDR catches suspicious behavior and enables hunting.
Q SPF, DKIM and DMARC together help:
+ Verify email sender authenticity and reduce spoofing/phishing
- Encrypt attachments
- Speed up email
- Back up mailboxes
E SPF authorizes senders, DKIM signs messages, DMARC sets policy + reporting.
Q Application allow-listing on endpoints:
+ Blocks unknown executables from running
- Allows any download
- Encrypts the disk
- Is the same as antivirus
E Strong against unknown malware, but needs upkeep.
Q "Sandboxing" a suspicious attachment means:
+ Detonating it in an isolated environment to observe behavior safely
- Deleting it
- Encrypting it
- Emailing it back
E Email gateways and EDR use sandboxes to catch unknown malware.
Q A key control against ransomware on endpoints is:
+ EDR + least privilege + tested offline backups + patching
- Only antivirus
- Disabling the firewall
- Sharing admin rights
E Layered defenses reduce both the chance and the impact.
Q "Host-based intrusion prevention" (HIPS) does what?
+ Blocks malicious behavior on the endpoint itself
- Filters the whole network
- Encrypts email
- Manages patches
E Complements EDR and host firewall.
Q Email attachment "content disarm and reconstruction" (CDR):

- Blocks all attachments
- Signs the message
E It removes macros/scripts while keeping the document usable.
