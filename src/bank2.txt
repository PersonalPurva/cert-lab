#D 11|RH124|Processes and signals|Identify CPU and memory intensive processes and kill processes; manage jobs.
Q Which signal does `kill PID` send when you give no signal?
+ SIGTERM (15)
- SIGKILL (9)
- SIGHUP (1)
- SIGINT (2)
E SIGTERM asks the program to exit cleanly. Use `kill -9` only when it refuses.
Q Which signal can a process NOT catch or ignore?
+ SIGKILL (9)
- SIGTERM (15)
- SIGHUP (1)
- SIGINT (2)
E SIGKILL and SIGSTOP are handled by the kernel directly.
C List all processes sorted by CPU usage, highest first.
A ps aux --sort=-%cpu
A ps aux --sort -%cpu
A ps -eo pid,user,%cpu,cmd --sort=-%cpu
E Use `--sort=-%mem` to sort by memory instead.
C Kill every process owned by user harry.
A pkill -u harry
A killall -u harry
A pkill -U harry
E `pgrep -u harry` lists the PIDs first so you can see what will be killed.
Q In top, which key sorts processes by memory usage?
+ M
- P
- k
- m
E P sorts by CPU, M by memory, k kills a PID, r renices, q quits.
C Start `sleep 1000` as a background job.
A sleep 1000 &
E The shell prints the job number and PID. `jobs` lists background jobs.
Q What does Ctrl+Z do to the program running in the foreground?
+ Stops (suspends) it; `bg` resumes it in the background
- Kills it with SIGKILL
- Moves it to the background while it keeps running
- Logs you out
E Ctrl+C sends SIGINT to end it. Ctrl+Z sends SIGTSTP to pause it.
C Bring job number 1 back to the foreground.
A fg %1
A fg 1
E `bg %1` resumes it in the background instead. `kill %1` sends it SIGTERM.
Q A process shows state `D` in ps. What does that mean?
+ Uninterruptible sleep, usually waiting for disk or network I/O
- It is a zombie
- It is stopped
- It is running on a CPU
E R running, S sleeping, T stopped, Z zombie, D uninterruptible sleep.
T Find and stop CPU hogs
S Start three CPU-heavy processes with `sha1sum /dev/zero &`. Find them with ps sorted by CPU and with top. Kill one by PID with SIGTERM, and kill the other two by name.
X for i in 1 2 3; do sha1sum /dev/zero & done
X ps aux --sort=-%cpu | head -5
X top          # press P, note a PID, press q
X kill <PID>
X pkill sha1sum
V pgrep -l sha1sum || echo "all gone"
T Find the biggest memory users
S Save the 5 processes using the most memory (with PID, user, %MEM and command) to /root/topmem.txt.
X ps -eo pid,user,%mem,cmd --sort=-%mem | head -6 > /root/topmem.txt
V cat /root/topmem.txt
T Job control drill
S Start `sleep 500` and `sleep 600` in the background and `sleep 700` in the foreground. Suspend the foreground job, resume it in the background, bring job 2 to the foreground and end it with Ctrl+C, then kill the rest by job number.
X sleep 500 &
X sleep 600 &
X sleep 700          # then press Ctrl+Z
X jobs
X bg %3
X fg %2             # then press Ctrl+C
X kill %1 %3
V jobs
T Pause and resume a process with signals
S As harry, start `sleep 900`. As root, stop it with SIGSTOP, confirm the state is T, resume it with SIGCONT, then kill it with SIGKILL.
X su - harry -c 'sleep 900 &'
X pgrep -u harry sleep
X kill -SIGSTOP <PID>
X ps -o pid,stat,cmd -p <PID>      # STAT shows T
X kill -SIGCONT <PID>
X kill -9 <PID>
V pgrep -u harry sleep || echo stopped

Q What does `systemctl mask atd` do?
+ Links the unit to /dev/null so it cannot be started at all, even manually
- Hides it from `systemctl list-units`
- Disables it at boot but still allows manual start
- Stops it and deletes its unit file

A systemctl list-units --failed
E Then run `systemctl status <unit>` and `journalctl -u <unit>` for details.
Q What is the difference between `systemctl reload` and `systemctl restart`?
+ reload tells the service to re-read its config without stopping; restart stops and starts it
- reload also enables the service at boot
- restart only works if reload fails
- There is no difference
E Not every service supports reload; `systemctl reload-or-restart` covers both cases.
Q You create or edit a unit file under /etc/systemd/system. What must you run next?
+ systemctl daemon-reload
- systemctl reboot
- systemctl reset-failed
- systemctl rescan
E systemd caches unit files. daemon-reload makes it read them again.

+ /etc/systemd/system
- /usr/lib/systemd/system
- /run/systemd/system
- /var/lib/systemd
E Package units live in /usr/lib/systemd/system. Files in /etc take priority. `systemctl edit unit` creates a drop-in override for you.
C Stop the atd service and stop it starting at boot, in one command.
A systemctl disable --now atd
A systemctl disable --now atd.service
A systemctl disable atd --now
E Confirm with `systemctl status atd`.
Q `systemctl status sshd` shows "Loaded: ... enabled; preset: enabled" and "Active: active (running)". What does that mean?
+ sshd is running now and will start at boot
- sshd is running but will not start at boot
- sshd starts at boot but is not running now
- sshd is masked
E "enabled" is the boot setting, "active" is the current state. They are separate.

T Write your own service
S Create /usr/local/bin/heartbeat.sh that writes "alive" to the journal every 30 seconds in a loop. Create heartbeat.service to run it, enable it at boot, and read its messages in the journal.
X printf '#!/bin/bash\nwhile true; do echo alive; sleep 30; done\n' > /usr/local/bin/heartbeat.sh
X chmod 755 /usr/local/bin/heartbeat.sh
X vim /etc/systemd/system/heartbeat.service

X # Description=Heartbeat demo

X systemctl enable --now heartbeat
V journalctl -u heartbeat -n 5

+ 700 on the directory and 600 on the file
- 755 and 644
- 777 and 666
- 750 and 640
E If they are too open, sshd ignores the key (StrictModes) and falls back to a password.
Q How do you stop root from logging in over SSH?
+ Set `PermitRootLogin no` in the sshd config, then reload sshd
- Remove root from /etc/passwd
- Set root's shell to nologin in /etc/ssh/ssh_config
- Delete /root/.ssh
E On RHEL 9 and 10 you can put the setting in a file under /etc/ssh/sshd_config.d/. /etc/ssh/ssh_config is the client config, not the server.

A sshd -t
A /usr/sbin/sshd -t
E No output means the syntax is valid. Then run `systemctl reload sshd`.
C Run `hostname` on servera as student without opening an interactive shell.
A ssh student@servera hostname
A ssh student@servera 'hostname'
E The command runs remotely and the output comes back to your terminal.
Q What is OpenSSH's built-in default for PermitRootLogin, which RHEL 9 and 10 use?
+ prohibit-password: root can log in with a key but not with a password
- yes
- no
- without-root
E Exam tasks often need root password login between exam nodes, or a key. Read the task carefully.
Q Where are the SSH server's own host keys stored?
+ /etc/ssh/ssh_host_*_key
- ~/.ssh/host_keys
- /var/lib/sshd/keys
- /etc/pki/ssh
E If a host is reinstalled, its host key changes and clients warn you. Remove the old line with `ssh-keygen -R host`.

X ssh student@node2 hostname

T Harden the SSH server
S On node2: stop root logging in over SSH and stop password logins for everyone. Make sure your key login works BEFORE you reload sshd, then test both.

- /var/log/secure is private
