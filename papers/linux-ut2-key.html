Q.1 — Predict the output (1 mark each)
a) -e enables escapes, so \n = newline and \t = tab:

b	c
b) 2750 = SGID + rwx(owner) + r-x(group) + ---(others). The SGID turns the group's x into s: 
drwxr-s---
c) 6 files (3 numbers × 2 letters): file1a.txt file1b.txt file2a.txt file2b.txt file3a.txt file3b.txt.
d) By the 3rd field (UID), numerically (-t: sets : as separator, -k3 the field, -n numeric).
e) Fields 1 and 7 — the username and the login shell of each account.

Q.2 — Write the command / pipeline (2 marks each)
a) 
cut -d: -f1 /etc/passwd | sort | head -n 5
b) 
grep -c '/bin/bash$' /etc/passwd
or: cut -d: -f7 /etc/passwd | grep -c /bin/bash
c) 
useradd -u 1600 -g devs -G wheel -s /sbin/nologin shikha
d) 
chmod 2770 /proj
2 = SGID, 7 = rwx owner, 7 = rwx group, 0 = nothing for others.
e) 
sed -i '5,10s/prod/dev/g' data
f) 
grep -v nologin /etc/passwd | cut -d: -f1
g) 
usermod -g class ram
usermod -aG wheel ram
-g changes the primary group; -aG appends a supplementary group.
Q.3 — Find the mistake (2 marks each)
a) Wrong: -G alone replaces all supplementary groups, so deep loses his existing ones. Fix: 
usermod -aG wheel deep
b) Wrong: the leading / in /Desktop points to the root of the filesystem, where you don't have write permission → "Permission denied". Fix (the Desktop in your home): 
cp report.txt Desktop      # or:  cp report.txt ~/Desktop
c) Wrong: groupadd 2083 creates a group literally named "2083". Fix (set the GID with -g): 
groupadd -g 2083 sales
d) Wrong: a syntax error in a hand-edited /etc/sudoers can lock everyone out of sudo. Use visudo, which checks the syntax before saving.
Q.4 — Scenario (9 marks)
A) (4) 
groupadd project
useradd -G project dev1
useradd -G project dev2
passwd dev1
B) (5) 
useradd lead
mkdir -p /srv/project
chown lead:project /srv/project
chmod 2770 /srv/project
su - dev1
touch /srv/project/file1
ls -l /srv/project
# file1's group is "project" — caused by the SGID bit
# (the 2 in 2770; shown as the 's' in drwxrws---).
— OR —
A) (4) 
sort -t: -k3 -n /etc/passwd | head -n 3 | cut -d: -f1,3
sorts by UID (field 3) numerically, takes the first 3, then shows username:UID.
B) (5) 
visudo
# add this single line:
%project ALL=(root) NOPASSWD: /usr/sbin/useradd

# test as dev1:
su - dev1
sudo useradd testuser      # works, no password
sudo cat /etc/shadow       # denied — only useradd is allowed
The %project means the group; NOPASSWD: limits it to exactly the useradd command.
